Diseña en cualquier dispositivo

Abre el editor en tu navegador o instala la aplicación Android de prueba. El editor admite proyectos propios JSON, DXF y apertura de DWG mediante conversión local en el navegador.

Abrir OtroCAD WebDescargar APK AndroidCódigo fuente

Android

Descarga el APK, permite instalar aplicaciones desde el navegador si Android lo solicita y abre OtroCAD. Requiere conexión a internet.

iPhone y iPad

Abre OtroCAD Web en Safari, pulsa Compartir y elige “Añadir a pantalla de inicio”. Se instala como acceso web.

Computadora

Abre el editor en Chrome, Edge o Firefox y selecciona Abrir para cargar archivos JSON, DXF o DWG.

Versión alfa: el APK Android es una compilación de pruebas firmada en modo debug; no es una versión de tienda ni un CAD profesional terminado.
