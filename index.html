Herramientas para crear

Dibujo 2D

Líneas, polilíneas, rectángulos, círculos, arcos, elipses, textos y directrices.

Precisión

Entrada dinámica de longitud y ángulo, coordenadas absolutas y relativas, ORTHO, POLAR y referencias a objetos.

Edición

Mover, copiar, OFFSET, rotar, simetría, escala, recortar, alargar y descomponer entidades compatibles. Selección CAD por ventana y cruce con grupos de objetos.

Anotación y capas

Cotas, hatch, colores, grosores de línea y organización por capas.

Archivos

Proyectos JSON, importación/exportación DXF, SVG y salida PDF/impresión.

Diseño adaptable

Interfaz web para PC y dispositivos táctiles, con guardado local y modo PWA.

Diseña en cualquier dispositivo

La versión web funciona en Chrome, Edge, Firefox y Safari. La PWA puede instalarse desde el navegador y conserva los recursos del editor para trabajar sin conexión después de la primera carga.

Usar OtroCAD Web Consultar compilaciones Android Código fuente

Android nativo

La versión 0.4.0 usa Android Canvas nativo, sin WebView ni permiso de Internet. Incluye selección CAD, grips arrastrables para editar geometría, autoguardado local y deshacer cambios. El APK debe superar la compilación y validación antes de instalarse. No uses el APK antiguo 0.1.0, que todavía dependía de WebView. El DWG directo aún no está disponible en el motor nativo.

iPhone y iPad

Abre OtroCAD Web en Safari, pulsa Compartir y elige “Añadir a pantalla de inicio”. Es una instalación PWA; no es una aplicación nativa de App Store.

Computadora

Abre el editor en Chrome, Edge o Firefox. Puedes abrir JSON y DXF. La conversión de DWG en la versión web carga un módulo externo y requiere conexión a Internet.

Versión alfa: las funciones CAD y la compatibilidad DXF aún son parciales. El APK Android de pruebas es debug y no está firmado para distribución de tienda. Verifica cotas, escala y archivos antes de utilizarlos en obra.
