# OtroCAD Windows 0.6.1 · motor arquitectónico local

El instalador de Windows incluye el editor CAD offline y la biblioteca de arquitectura **El Arqui · Motor Local**, sin acceso a IA en línea, cuentas, variables API ni créditos.

La aplicación conserva las herramientas CAD, DXF/DWG mediante componentes locales disponibles, y un generador preliminar de vivienda que dibuja escaleras en U, puertas, ventanas, muebles, muros y cotas editables. Todo ocurre localmente. El instalador no está firmado y sigue siendo experimental; la compilación y apertura se verifican en GitHub Actions, pero hace falta la revisión manual en un PC físico.

Más información: [biblioteca arquitectónica estática](../docs/EL_ARQUI_MOTOR_LOCAL.md).
