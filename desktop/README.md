# OtroCAD para Windows (experimental)

Empaqueta el editor web existente con Electron y archivos locales. El programa bloquea peticiones de red. Aún no ofrece DWG auténtico y no tiene todas las capacidades de una aplicación CAD nativa. La prueba automática instala y abre el editor; no reemplaza las pruebas de edición y persistencia en un equipo real. El instalador de prueba no está firmado.
