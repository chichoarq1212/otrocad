# OtroCAD

CAD 2D para arquitectura e ingeniería, con editor web adaptable a computadora, tablet y Android.

## Acceso

- Editor web: https://cdn.jsdelivr.net/gh/chichoarq1212/otrocad@main/editor/index.html
- Página de inicio: https://cdn.jsdelivr.net/gh/chichoarq1212/otrocad@main/index.html
- APK Android de pruebas: https://github.com/chichoarq1212/otrocad/releases/download/android-alpha-0.1.0/app-debug.apk

## Herramientas de esta versión alfa

- Dibujo de líneas, polilíneas, rectángulos, círculos, arcos, elipses, polígonos, cotas y textos.
- Vista previa discontinua en tiempo real, con longitud y ángulo dinámicos.
- Capas, colores, grosor de línea y tipo de línea.
- Referencias, rejilla, ortogonal, polar, zoom, encuadre, deshacer y rehacer.
- Abrir JSON, DXF y DWG; guardar proyectos JSON y exportar DXF, SVG e impresión PDF.
- En Android, el selector de archivos y el diálogo nativo para guardar se integran con el editor web.

## Notas importantes

OtroCAD se encuentra en fase alfa. El APK es una aplicación Android WebView firmada en modo debug, requiere conexión a internet y todavía no es una aplicación offline ni una versión para distribución comercial. La conversión DWG utiliza el paquete @cadview/dwg y LibreDWG WebAssembly; el paquete tiene licencia GPL-3.0. Verifica siempre los archivos importados y las medidas antes de utilizarlos en obra.
